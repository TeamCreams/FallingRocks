PROJECT SUMMARY

프로젝트 개요와 핵심 특징

Suberunker는 하늘에서 끊임없이 떨어지는 돌을 피하며 생존하는 2D 아케이드 액션 게임입니다. 플레이어는 캐릭터를 좌우로 조작하여 낙하하는 돌들을 피하며, 시간이 지날수록 난이도가 증가하는 도전적인 게임플레이를 경험할 수 있습니다. 간단한 조작과 직관적인 게임 메커니즘으로 누구나 쉽게 즐길 수 있으며, 스코어 시스템을 통해 자신의 기록을 갱신하는 재미를 제공합니다.

게임은 단순한 회피 게임을 넘어, 아이템 시스템과 캐릭터 커스터마이징, 그리고 온라인 랭킹 시스템을 통해 지속적인 플레이 동기를 부여합니다. Firebase를 활용한 실시간 데이터 동기화와 SignalR 기반의 멀티플레이어 기능으로 다른 플레이어들과 경쟁할 수 있는 소셜 요소도 갖추고 있습니다.

Key Features

  • 🎯 단순하지만 중독성 있는 회피 게임플레이
  • 📈 시간에 따라 증가하는 동적 난이도 시스템
  • 🎨 다양한 캐릭터 커스터마이징 옵션
  • 🏆 실시간 온라인 랭킹 및 스코어 시스템
  • 🎁 랜덤 아이템 시스템으로 전략적 플레이 제공
  • 🌐 Firebase 및 SignalR 기반 실시간 멀티플레이어 지원

TECHNICAL FEATURES

주요 기술적 구현 사항

🎮

Unity 기반 크로스 플랫폼 개발

Unity 엔진을 활용하여 PC와 Android 플랫폼을 동시에 지원하는 게임을 개발했습니다. 플랫폼별 최적화와 입력 방식(조이스틱/키보드) 차이를 고려한 유연한 컨트롤 시스템을 구현했습니다.

🔄

오브젝트 풀링 시스템

지속적으로 생성되고 파괴되는 돌(Stone)과 파편(StoneShard) 오브젝트를 효율적으로 관리하기 위해 오브젝트 풀링 패턴을 구현했습니다. 이를 통해 메모리 할당/해제로 인한 성능 저하를 방지했습니다.

📊

동적 난이도 조절 시스템

게임 진행 시간과 스테이지에 따라 돌의 생성 빈도와 패턴이 변화하는 동적 난이도 시스템을 개발했습니다. StoneShower 패턴을 포함한 다양한 도전 요소로 플레이어에게 지속적인 긴장감을 제공합니다.

🔥

Firebase 통합 및 실시간 데이터 동기화

Firebase Authentication을 통한 소셜 로그인(Google) 기능과 Realtime Database를 활용한 플레이어 데이터, 스코어, 랭킹 정보의 실시간 동기화를 구현했습니다.

🌐

SignalR 기반 실시간 통신

ASP.NET Core SignalR을 활용하여 실시간 멀티플레이어 통신 시스템을 구축했습니다. 게임 서버와 클라이언트 간 양방향 실시간 데이터 전송을 통해 동시 접속 플레이어 관리 및 이벤트 처리를 수행합니다.

🎯

이벤트 기반 아키텍처

게임 내 다양한 상호작용(플레이어 공격, 아이템 획득, 스테이지 업 등)을 이벤트 시스템으로 관리하여 컴포넌트 간 결합도를 낮추고 유지보수성을 향상시켰습니다.

LEARNING POINTS

프로젝트를 통해 배운 점

🎮

게임의 핵심 재미 요소 설계

단순한 게임 메커니즘이지만 플레이어에게 지속적인 재미를 제공하기 위해서는 적절한 난이도 곡선과 보상 시스템이 중요하다는 것을 배웠습니다. 난이도 데이터를 체계적으로 관리하고, 스테이지별로 적절히 조절하는 방법을 익혔습니다.

⚡

모바일 게임 성능 최적화

모바일 환경에서 안정적인 프레임 레이트를 유지하기 위해 오브젝트 풀링, 메모리 관리, 렌더링 최적화 등 다양한 성능 개선 기법을 적용했습니다. 특히 안드로이드 기기의 다양한 스펙을 고려한 최적화 전략을 수립하는 경험을 쌓았습니다.

🔗

백엔드 연동 및 API 설계

ASP.NET Core로 구축한 게임 API 서버와 Unity 클라이언트를 연동하며 RESTful API 설계, 데이터 직렬화/역직렬화, 에러 처리 등 백엔드 통신의 전반적인 과정을 이해하게 되었습니다. 특히 비동기 통신 처리와 네트워크 에러 핸들링의 중요성을 깨달았습니다.

📱

크로스 플랫폼 UI/UX 설계

PC와 모바일에서 동일한 게임 경험을 제공하면서도 각 플랫폼의 특성에 맞는 UI/UX를 설계하는 방법을 배웠습니다. 화면 비율 대응, 터치/마우스 입력 처리, 조이스틱 컨트롤 등 플랫폼별 인터페이스 최적화를 경험했습니다.

👥

소셜 기능 및 랭킹 시스템 구현

Firebase를 활용한 소셜 로그인, 실시간 랭킹 시스템을 구현하며 사용자 간 경쟁과 소셜 요소가 게임의 재미와 지속성에 얼마나 큰 영향을 미치는지 이해하게 되었습니다. 온라인 기능 구현 시 보안과 데이터 무결성을 고려하는 방법도 익혔습니다.

🛠️

유지보수 가능한 코드 구조

Manager 패턴과 이벤트 기반 아키텍처를 적용하여 확장 가능하고 유지보수가 용이한 코드 구조를 설계했습니다. 특히 게임 데이터를 외부 파일로 관리하여 코드 수정 없이도 게임 밸런스를 조정할 수 있는 시스템을 구축했습니다.
