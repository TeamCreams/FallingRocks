## 🎮 Game Overview

Suberunker는 하늘에서 끊임없이 떨어지는 돌을 피하며 생존하는 게임입니다.
- **플랫폼**: PC / Android
- **장르**: 2D 아케이드 액션 생존
- **엔진**: Unity
- **기술 스택**: C#, Firebase, SignalR, ASP.NET Core

## 🚀 Key Features

- 단순하지만 중독성 있는 회피 게임플레이
- 시간에 따라 증가하는 동적 난이도 시스템
- 다양한 캐릭터 커스터마이징
- 실시간 온라인 랭킹 및 스코어 시스템
- Firebase 및 SignalR 기반 멀티플레이어 지원
